Local two-player Pong example built with Unity and C#.

## Getting started

- Clone the repository and add `.` to Unity Hub as an existing project.

- Use the recorded Editor version as the starting point. For an upgrade, work on a separate branch and preserve all `.meta` files and serialized asset references.

- Open a project scene in the Editor and enter Play mode. Available scene examples: [Assets/Scenes/Menu.unity](https://github.com/kleberandrade/pong/blob/master/Assets/Scenes/Menu.unity), [Assets/Scenes/Table.unity](https://github.com/kleberandrade/pong/blob/master/Assets/Scenes/Table.unity).
